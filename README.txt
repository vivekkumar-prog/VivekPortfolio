PORTFOLIO SETUP

1. Open index.html in VS Code / Live Server.
2. The portfolio is already responsive for desktop, tablet and mobile.
3. Replace profile-placeholder.svg with your real photo:
   - Rename your photo to: profile.jpg
   - Put profile.jpg in this same folder.
   - In index.html and about.html, change:
     src="profile-placeholder.svg"
     to:
     src="profile.jpg"
4. Update your email, phone and social links in contact.html.
5. Replace # in project links with your real GitHub/live project URLs.
